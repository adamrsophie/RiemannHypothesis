The final statements

The whole project exists to make five theorems in lean/src/Main.lean typecheck. Their statements use only Mathlib definitions, so you can read and trust them without opening any of the other 175,185 files.

The two root files

The Main library has exactly two roots. Statements.lean imports only Mathlib and defines four propositions. Main.lean imports those definitions together with the proof, and states the theorems.

Statements.lean

import Mathlib

def RiemannZetaZerosOnLine : Prop :=
  ∀ s : ℂ, riemannZeta s = 0 → (¬∃ n : ℕ, s = -2 * ((n : ℂ) + 1)) → s ≠ 1 → s.re = 1 / 2

def DirichletLNonvanishingRightOfHalf : Prop :=
  ∀ (N : ℕ) [NeZero N] (χ : DirichletCharacter ℂ N) (s : ℂ),
    1 / 2 < s.re → (χ ≠ 1 ∨ s ≠ 1) → DirichletCharacter.LFunction χ s ≠ 0

def DirichletLZerosOnLine : Prop :=
  ∀ (N : ℕ) [NeZero N] (χ : DirichletCharacter ℂ N) (s : ℂ),
    0 < s.re → s.re < 1 → DirichletCharacter.LFunction χ s = 0 → s.re = 1 / 2

def PrimitiveDirichletLZerosOnLine : Prop :=
  ∀ (N : ℕ) [NeZero N] (χ : DirichletCharacter ℂ N), χ.IsPrimitive →
    ∀ s : ℂ, 0 < s.re → s.re < 1 → DirichletCharacter.LFunction χ s = 0 → s.re = 1 / 2

Each theorem explained

riemannHypothesis

Type: Mathlib's RiemannHypothesis, defined in Mathlib/NumberTheory/LSeries/RiemannZeta.lean as

def RiemannHypothesis : Prop :=
  ∀ (s : ℂ) (_ : riemannZeta s = 0) (_ : ¬∃ n : ℕ, s = -2 * (n + 1)) (_ : s ≠ 1), s.re = 1 / 2

In words: if \(\zeta(s) = 0\), \(s\) is not a trivial zero \(-2, -4, \dots\), and \(s \ne 1\), then \(\operatorname{Re} s = \tfrac12\). The condition \(s \ne 1\) is only there because Mathlib's total function has some value at the pole. Using Mathlib's own definition matters: the statement was written by the Mathlib community long before this project, so the project could not have weakened it.

riemannZeta_eq_zero_re

The same statement written out by hand in Statements.lean as RiemannZetaZerosOnLine. The only difference is the explicit cast ((n : ℂ) + 1). It is proved by the same term rhOfAll, which shows the two definitions agree definitionally, and gives a reader a copy of the statement they can see without opening Mathlib.

LFunction_ne_zero_of_half_lt_re

$$\forall N \ge 1,\ \forall \chi \bmod N,\ \forall s,\quad \operatorname{Re} s > \tfrac12 \ \wedge\ (\chi \ne 1 \vee s \ne 1) \ \Longrightarrow\ L(s,\chi) \ne 0.$$

This is the heart of the project. Every other theorem is derived from it in a few lines (see Proof structure). Notes on the formulation:

  • [NeZero N] excludes the meaningless modulus 0.
  • χ ≠ 1 ∨ s ≠ 1 excludes only the pole of the trivial character's L-function at \(s=1\), where Lean's value is junk. Note that for \(N > 1\) the trivial character mod \(N\) is imprimitive, and its L-function is \(\zeta(s)\prod_{p\mid N}(1-p^{-s})\).
  • It covers all characters, including imprimitive ones, and all \(s\) to the right of \(\tfrac12\), including \(\operatorname{Re} s \ge 1\) where nonvanishing was already classical.

LFunction_eq_zero_re

$$\forall N,\ \forall \chi \bmod N,\ \forall s,\quad 0 < \operatorname{Re} s < 1 \ \wedge\ L(s,\chi) = 0 \ \Longrightarrow\ \operatorname{Re} s = \tfrac12.$$

GRH for every Dirichlet L-function. The strip condition \(0 < \operatorname{Re} s\) is necessary, not a weakening: imprimitive L-functions really do vanish on \(\operatorname{Re} s = 0\) because of their extra Euler factors (see Background).

LFunction_eq_zero_re_of_isPrimitive

The same for primitive characters only. It is logically weaker than LFunction_eq_zero_re, but it is proved by a separate, very short route (critAll), which makes it the most transparent of the strip statements.

What you have to trust

ComponentWhy it is trusted
The Lean 4 kernelSmall, heavily scrutinized type checker. Independent reimplementations exist and can replay the proof.
Mathlib definitions used in the statementsriemannZeta, DirichletCharacter, DirichletCharacter.LFunction, IsPrimitive, RiemannHypothesis, and the basic number systems. Written and reviewed by the Mathlib community, independently of this project.
Statements.leanFour definitions, shown in full above.
The axioms usedMust be only propext, Classical.choice and Quot.sound. This is checked with #print axioms; see Verify.

You do not have to trust or even read the remaining 175,185 files. If the kernel accepts them and no extra axioms appear, their content is irrelevant to the truth of the statements. This is the point of releasing a formal proof instead of a 250,000 page manuscript.

Things a careful reader should check

  • That the build uses the Mathlib commit pinned in lake-manifest.json, and that this commit's RiemannHypothesis and LFunction are the standard definitions (they are ordinary Mathlib, not a fork: the dependency URL is leanprover-community/mathlib4).
  • That no file in the project redefines or shadows these names. A redefinition would have to live in a different namespace, and #check @riemannHypothesis after import Main shows the fully elaborated type.
  • That #print axioms is clean for all five theorems.
