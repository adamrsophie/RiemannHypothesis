Guide

Proof structure

The top of the proof is short and readable. Every final theorem is derived, in a few dozen lines that use only Mathlib, from one statement: no Dirichlet L-function vanishes to the right of the critical line. This page walks through those reductions and shows where the deep part begins.

Scope. Everything on this page was read directly from the Lean source. Below the point marked "where the depth is", the roughly 175,000 remaining files have not been read for this guide, and nothing here explains their mathematics.

The key statement

def UpperTheory.EveryCharacter : Prop :=
  ∀ (N : ℕ) [NeZero N] (χ : DirichletCharacter ℂ N) (s : ℂ),
    1 / 2 < s.re → (χ ≠ 1 ∨ s ≠ 1) → DirichletCharacter.LFunction χ s ≠ 0

This is word for word DirichletLNonvanishingRightOfHalf from Statements.lean. Each of the following reductions takes EveryCharacter as a hypothesis h.

Step 1: zeta, from right to left

Formalism.VW.rh_of_right imports only Mathlib. It proves

$$\Big(\forall s,\ \operatorname{Re} s > \tfrac12,\ s \ne 1 \Rightarrow \zeta(s) \ne 0\Big) \ \Longrightarrow\ \text{RH}.$$

Take a zero \(s\) that is not trivial and not 1. Split on \(\operatorname{Re} s\) versus \(\tfrac12\):

  • \(\operatorname{Re} s = \tfrac12\): done.
  • \(\operatorname{Re} s > \tfrac12\): contradicts the hypothesis.
  • \(\operatorname{Re} s < \tfrac12\): use the functional equation riemannZeta_one_sub at the point \(1-s\):
    $$\zeta(s) = 2\,(2\pi)^{-(1-s)}\,\Gamma(1-s)\,\cos\!\Big(\frac{\pi(1-s)}{2}\Big)\,\zeta(1-s).$$
    The left side is 0. The proof shows each factor on the right is nonzero: \(2(2\pi)^{s-1} \ne 0\); \(\Gamma(1-s) \ne 0\) because \(\operatorname{Re}(1-s) > 0\); and \(\cos(\pi(1-s)/2) = 0\) would force \(s = -2k\) for an integer \(k\), and every such \(s\) is excluded: \(k<0\) gives \(\operatorname{Re} s \ge 2\), contradicting \(\operatorname{Re} s < \tfrac12\); \(k=0\) gives \(s=0\), but \(\zeta(0) = -\tfrac12 \ne 0\); \(k > 0\) gives a trivial zero. Finally \(\zeta(1-s) \ne 0\) by the hypothesis, since \(\operatorname{Re}(1-s) > \tfrac12\). Contradiction.

Step 2: zeta is an L-function

theorem Formalism.VW.rh_of_every (h : UpperTheory.EveryCharacter) : RiemannHypothesis :=
  Formalism.VW.rh_of_right fun s hs hs1 => by
    have := h 1 (1 : DirichletCharacter ℂ 1) s hs (Or.inr hs1)
    rwa [LFunction_modOne_eq] at this

Apply EveryCharacter to the trivial character modulo 1. Mathlib's LFunction_modOne_eq says its L-function is riemannZeta. This gives exactly the hypothesis of Step 1.

Step 3: GRH for primitive characters

Formalism.VW.critLine proves the strip statement for a primitive \(\chi\). Suppose \(L(s,\chi) = 0\) with \(0 < \operatorname{Re} s < 1\).

  1. Right of the line. If \(\operatorname{Re} s > \tfrac12\), EveryCharacter says \(L(s,\chi) \ne 0\). Contradiction.
  2. Gamma factor is harmless. Mathlib writes \(L(s,\chi) = \Lambda(s,\chi) / \gamma_\chi(s)\) (LFunction_eq_completed_div_gammaFactor), where \(\gamma_\chi(s) = \Gamma_{\mathbb R}(s)\) or \(\Gamma_{\mathbb R}(s+1)\) by parity. The lemma gammaFactor_ne_zero shows \(\gamma_\chi(s) \ne 0\) when \(\operatorname{Re} s > 0\). So \(\Lambda(s,\chi) = 0\).
  3. Reflect. \(\chi^{-1}\) is primitive too (same conductor, conductor_inv). The functional equation IsPrimitive.completedLFunction_one_sub for \(\chi^{-1}\) expresses \(\Lambda(1-s,\chi^{-1})\) as a nonzero constant times \(\Lambda(s,\chi)\), hence \(\Lambda(1-s,\chi^{-1}) = 0\) and so \(L(1-s,\chi^{-1}) = 0\).
  4. Contradiction. If \(\operatorname{Re} s < \tfrac12\) then \(\operatorname{Re}(1-s) > \tfrac12\), and EveryCharacter applied to \(\chi^{-1}\) at \(1-s\) forbids this zero.
Show the full Lean source 
theorem Formalism.VW.critLine (h : UpperTheory.EveryCharacter) (N : ℕ) [NeZero N]
    (χ : DirichletCharacter ℂ N) (hχ : χ.IsPrimitive) (s : ℂ)
    (h0 : 0 < s.re) (h1 : s.re < 1) (hz : LFunction χ s = 0) : s.re = 1 / 2 := by
  have hs0 : s ≠ 0 := fun e => by simp [e] at h0
  have hs1 : s ≠ 1 := fun e => by simp [e] at h1
  by_contra hne
  rcases lt_or_gt_of_ne hne with hlt | hgt
  · have hinv : χ⁻¹.IsPrimitive := by
      rw [isPrimitive_def, conductor_inv]; exact hχ
    have hc : completedLFunction χ s = 0 := by
      rw [LFunction_eq_completed_div_gammaFactor χ s (Or.inl hs0)] at hz
      exact (div_eq_zero_iff.1 hz).resolve_right (Formalism.VW.gammaFactor_ne_zero χ h0)
    have hfe := hinv.completedLFunction_one_sub s
    rw [inv_inv, hc, mul_zero] at hfe
    have h2 : (1 - s) ≠ 0 := sub_ne_zero.2 hs1.symm
    refine h N χ⁻¹ (1 - s) (by rw [sub_re, one_re]; linarith)
      (Or.inr fun e => hs0 (by linear_combination -e)) ?_
    rw [LFunction_eq_completed_div_gammaFactor χ⁻¹ (1 - s) (Or.inl h2), hfe, zero_div]
  · exact h N χ s hgt (Or.inr hs1) hz

Step 4: GRH for all characters

Claim.strip in ClaimStrip.lean removes the primitivity assumption. Given any \(\chi\) mod \(N\) and a zero in the strip:

  • prim_zero: the zero is also a zero of the primitive character \(\chi^*\) inducing \(\chi\). Mathlib's LFunction_changeLevel gives \(L(s,\chi) = L(s,\chi^*) \prod_{p \mid N} (1 - \chi^*(p) p^{-s})\), and factor_ne_zero shows each Euler factor is nonzero when \(\operatorname{Re} s > 0\), because \(|\chi^*(p)\,p^{-s}| \le p^{-\operatorname{Re} s} < 1\).
  • prim_reflect: the argument of Step 3 sends this to a zero of \(L(1-s, (\chi^*)^{-1})\).
  • If \(\operatorname{Re} s < \tfrac12\), EveryCharacter at modulus χ.conductor rules that out; if \(\operatorname{Re} s > \tfrac12\), it rules out the original zero directly.

The same file also gives a second, independent derivation of RH, Claim.zeta, via the completed zeta function completedRiemannZeta_one_sub, and records Claim.zeta_iff : Zeta ↔ RiemannHypothesis := Iff.rfl.

Where the depth is

All of the above is routine analytic number theory, already supported by Mathlib. The entire weight of the project lies in the single term

theorem UpperTheory.FinalTheorems.everyCharacter : UpperTheory.EveryCharacter :=
  UpperTheory.FinalTheorems.everyCharacter_of_row
    UpperTheory.Gal.Int.galoisLocalGlobalStrong_recParameter

theorem UpperTheory.FinalTheorems.everyCharacter_of_row
    (h : UpperTheory.GalStar.Row0b fun h rc => UpperTheory.Zero.LLC.IsRecT h rc) :
    UpperTheory.EveryCharacter :=
  UpperTheory.LiteratureTheorems.every_character_of_literature_of_vWin
    ⟨h, UpperTheory.Zero.LLC.recTExists, h⟩ (UpperTheory.One.vwin_of_row h)

Its four ingredients are named after a Galois local global compatibility statement (galoisLocalGlobalStrong_recParameter), the existence of local Langlands parameters (Zero.LLC.recTExists), a quantitative condition VWin, and a bundle of literature inputs (LiteratureTheorems). Each of these is itself a proved theorem inside the project, not an assumption: the text search found no axiom or sorry anywhere.

One layer down: reduction to primitive characters

Next to the main route, CharacterBoxes/EveryCharacter.lean shows the shape of the inner argument. The project works with a structure of primitive characters,

structure Formalism.HC.PChar where
  N : ℕ
  [ne : NeZero N]
  χ : DirichletCharacter ℂ N
  prim : χ.IsPrimitive

def PChar.ZeroFreeAbove (ψ : PChar) (θ : ℝ) : Prop :=
  ∀ s : ℂ, θ < s.re → DirichletCharacter.LFunction ψ.χ s ≠ 0

def ZeroFreeAll : Prop := ZeroFreeOn fun _ => True   -- every ψ is zero free above 1/2

and UpperTheory.Top.imprimitive : ZeroFreeAll → EveryCharacter passes from primitive to all characters with the same Euler factor argument as Step 4. The quantitative hypothesis is

def VWin : Prop := ∀ ψ : PChar, VWinAt ψ 401

where VWinAt asks, for every small \(\varepsilon \in (0, \tfrac1{52})\) and scales \(X\), for bounds VVle on certain number fields attached to \(\psi\) (IsChiField) in a window \(Y \le x \le Y^2\). Interpreting these objects would require reading far more of the code and is left to experts. The note gives Alpöge's informal description of the ideas.
