Frequently asked questions

Short answers to the questions people ask first.

Status

Is the Riemann Hypothesis proved?

It is claimed to be. If lake build Main succeeds and #print axioms riemannHypothesis lists only Lean's three standard axioms, then the Lean kernel has checked a proof of Mathlib's statement of RH, and that is very strong evidence. This site has not run those checks. See Verify.

Does anyone understand the proof?

Not fully yet, by the author's own account. The note says Alpöge has not yet "mastered a massive neighbourhood around its mathematics", that parts were found by Claude, and that he intends to understand, simplify and write it up. A formal proof can be correct before it is understood; understanding is a separate, later achievement.

Why should a formal proof be believed if no one has read it?

Because correctness reduces to three small things: the Lean kernel, the Mathlib definitions used in the statement, and the absence of extra axioms. None of these depend on the 175,000 proof files. See What you have to trust.

Scope

Does it prove GRH?

It claims GRH for Dirichlet L-functions: all zeros in \(0 < \operatorname{Re} s < 1\) of \(L(s,\chi)\), for every Dirichlet character \(\chi\), lie on \(\operatorname{Re} s = \tfrac12\). It does not cover L-functions of general number fields, modular forms, or other automorphic representations.

What about the Extended Riemann Hypothesis?

Not included. The note says Alpöge expects it "with more time".

What follows if it is correct?

Every theorem in the literature conditional on RH or GRH for Dirichlet L-functions becomes unconditional, for example sharp error terms in the prime number theorem and in its version for arithmetic progressions, and the \(O(\log^2 N)\) bound for the least quadratic nonresidue, which makes the Miller primality test deterministic in polynomial time.

Size

Why is it so large?

The note says "an astounding amount of mathematics is present in the argument", touching automorphic forms on higher rank groups, theta correspondences, Iwasawa theory, Arakelov geometry and more. Most of this was not in Mathlib, so it had to be formalized from scratch. The author also writes that he may have "baked lots of strange suboptimal choices into the argument" and expects much shorter proofs to follow.

How long does it take to build?

Unknown here. Expect many hours on a large machine. If you build it, please report your numbers.

This repository

Has the code been modified?

No. The lean/ directory is the archive exactly as distributed, verified by git tree hash against another independent mirror (jsmorph/rh). Only README.md, .gitignore and this website in docs/ were added.

Where is the original?

Alpöge distributed it as https://alpo.ge/lean.tar.gz.part01 through part14, linked from the first footnote of remark.pdf. The joined archive is 239,275,554 bytes.

Is this site affiliated with the author?

No. It is an independent, unofficial guide.

What is the license?

The archive contains no license file, so no license is granted here, and copyright in the Lean code stays with Levent Alpöge. This mirror exists for study and verification and will be taken down if the author asks.
