Project layout

The project is a single Lake package named tree with eleven library targets and 175,187 Lean files. This page maps where the files are. Descriptions come from directory names only; the files themselves have not been read.

Top level

lean/
├── lean-toolchain          leanprover/lean4:v4.33.1
├── lakefile.toml           package "tree", library targets, Lean options
├── lake-manifest.json      pinned Mathlib and its dependencies
└── src/
    ├── Statements.lean     the four propositions (imports only Mathlib)
    ├── Main.lean           the five final theorems

Build configuration

name = "tree"
srcDir = "src"
defaultTargets = ["BuildAid", "CompanionTheory", "Development", "Formalism", "GroundTheory",
  "GroundTheoryFields", "Lemmata", "PositivityTheory", "ReciprocityTheory", "Supplements", "Main"]
moreLeanArgs = ["--tstack=400000"]

[leanOptions]
autoImplicit = false
relaxedAutoImplicit = false
maxSynthPendingDepth = 3
pp.unicode.fun = true
maxHeartbeats = 4000000

[[require]]
name = "mathlib"
git = "https://github.com/leanprover-community/mathlib4"
rev = "0df444a360eaa60ab8c11dca51a86af692955474"
SettingMeaning
autoImplicit = falseUnknown identifiers are errors, not silently bound variables. A standard safety setting.
maxHeartbeats = 400000020 times Lean's default elaboration budget per declaration. Affects how long tactics may run, not soundness.
maxSynthPendingDepth = 3Allows deeper nested type class problems during elaboration.
--tstack=400000Larger thread stack for the Lean process, for deep terms.
Mathlib pinAn exact commit of the official leanprover-community/mathlib4, not a fork.

None of these options affect what the kernel accepts. They only change resource limits during elaboration.
